# 뮤직 — 아이폰용 음악 플레이어

사파리에서 열어 홈 화면에 추가해 쓰는 웹앱입니다.

**주소:** https://km050.github.io/IPO/

## 아이폰에 설치하기
1. 아이폰 사파리에서 위 주소를 엽니다.
2. 아래쪽 **공유** 버튼 → **홈 화면에 추가**를 누릅니다.
3. 홈 화면의 **뮤직** 아이콘으로 실행합니다.

## Windows PC에서 음악 넣기
1. PC 브라우저에서 https://github.com/km050/IPO/tree/main/music 을 엽니다.
2. **Add file → Upload files**를 누르고 음악 파일을 끌어다 놓습니다.
3. 아래 **Commit changes**를 누릅니다.
4. 1~2분 뒤 아이폰 앱을 다시 열면 목록에 나타납니다.

- 지원 형식: mp3, m4a, aac, wav, flac
- 파일 이름을 `가수 - 제목.mp3`로 하면 가수와 제목이 나뉘어 표시됩니다.
- 한 파일은 최대 100MB, 웹 업로드는 한 번에 25MB까지가 편합니다.

> ⚠️ 이 저장소는 **공개(Public)** 라서 `music` 폴더의 파일은 누구나 받을 수 있습니다.
> 남에게 공개되면 안 되는 음악은 아래 "폰에서 추가" 방식을 쓰세요.

## 폰에서 직접 넣기 (비공개)
앱 오른쪽 위 **＋ 폰에서 추가** → 파일 앱(iCloud Drive 등)에서 곡 선택.
곡은 이 폰 안에만 저장되고 인터넷에 올라가지 않습니다.
Windows용 iCloud를 쓰면 PC에서 iCloud Drive 폴더에 넣은 음악을 이 방법으로 가져올 수 있습니다.
