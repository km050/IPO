# 뮤직 — PC 음악을 Wi-Fi로 아이폰에서 듣기

Windows PC의 음악 폴더를 **같은 Wi-Fi**에 있는 아이폰에서 재생하는 프로그램입니다.
음악은 인터넷에 올라가지 않고 집 안 네트워크 안에서만 오가며, PIN이 있어야 접속할 수 있습니다.

## 1. PC에 설치
1. [최신 버전 다운로드](https://github.com/km050/IPO/releases/latest) → **MusicPlayer.exe** 를 받습니다.
2. 실행합니다. (설치 과정 없음)
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**
   - 방화벽 창이 뜨면 **개인 네트워크**에 체크하고 **허용**
3. **폴더 바꾸기**로 음악이 있는 폴더를 고릅니다. (기본: 내 PC의 `음악` 폴더)

## 2. 아이폰 연결
1. 아이폰이 PC와 **같은 Wi-Fi**인지 확인합니다.
2. 아이폰 **카메라**로 PC 화면의 QR을 찍고, 뜨는 링크를 누릅니다.
   (QR이 안 되면 사파리에 화면의 주소를 입력하고 PIN을 넣으세요.)
3. 사파리 **공유 → 홈 화면에 추가**를 하면 앱처럼 쓸 수 있습니다.

## 음악 추가
PC의 음악 폴더에 파일을 넣고, 아이폰 앱에서 **새로고침**을 누르면 됩니다.
- 지원 형식: mp3, m4a, aac, wav, flac, aiff
- 곡 정보(제목·가수·앨범·앨범아트)를 파일에서 자동으로 읽습니다.
  정보가 없으면 `가수 - 제목.mp3` 형식의 파일 이름을 씁니다.

## 기능
재생/일시정지 · 이전/다음 · 탐색 · 셔플 · 전체/한 곡 반복 · 검색 · 앨범아트 · 잠금화면 컨트롤 · 마지막 곡 기억

## 알아둘 점
- PC 프로그램 창이 켜져 있어야 재생됩니다. PC가 잠자기에 들어가면 끊깁니다.
- 밖에서(LTE/5G)는 연결되지 않습니다. 같은 Wi-Fi에서만 작동합니다.
- PIN을 바꾸면 연결된 아이폰은 다시 연결해야 합니다.

## 개발자용
```
cd desktop
pip install qrcode mutagen
python app.py            # 창 화면
python server.py <폴더>   # 창 없이 서버만
```
`main` 에 올리면 GitHub Actions가 `MusicPlayer.exe` 를 자동으로 빌드해 Releases에 올립니다.
